# AWIC Public Website Mockup

A premium static website concept for the Association for Women in Cryptocurrency.

## Important

This repository is an independent portfolio mockup created by **Phoenix Securitas Tech**. It is not the official AWIC website and is not represented as an approved AWIC project.

## Features

- Premium dark Web3 visual direction using AWIC-inspired magenta, purple, cyan, and gold
- Responsive homepage
- Animated network particles and globe
- Mobile navigation
- Scroll reveal animations
- Animated statistics
- Membership, events, education, community, sponsors, and contact sections
- Accessible semantic HTML
- Reduced-motion support
- Demo newsletter interaction
- No framework or build process required

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension.

## Deploy to GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this folder.
3. Open the repository **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/root`.
7. Save.

Your live mockup will appear at:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY-NAME/`

## Files

- `index.html` – complete homepage
- `assets/style.css` – layout, responsive styling, and animations
- `assets/script.js` – navigation, counters, particles, and form demo
- `preview.png` – original visual direction reference

## Customize

Search for these values in `assets/style.css`:

```css
--pink: #ff2fa4;
--magenta: #e5007d;
--purple: #9f4cff;
--cyan: #27d8ff;
--gold: #f7c948;
```

Replace sample event information, statistics, sponsor placeholders, links, and contact details before presenting it as a production proposal.
