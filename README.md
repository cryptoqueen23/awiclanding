# AWIC Complete Redesign Concept

A GitHub-ready static concept containing:

- Premium public landing website
- Responsive member dashboard with animated globe
- Mobile navigation
- Keyboard accessibility and visible focus states
- Skip links and semantic landmarks
- Reduced-motion support
- High-contrast dark theme designed toward WCAG 2.2 AA

## Run locally
Open `index.html` or use a local static server.

## Deploy
Upload the entire folder to GitHub and deploy with GitHub Pages or Vercel. The member portal is located at `/member/`.

Independent portfolio mockup by Phoenix Securitas Tech. Not an official AWIC website.
